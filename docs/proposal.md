# 需求文档（Proposal）

> 阶段一：需求定义 — 完成于 2026-05-27

---

## 项目概述

**项目名称**：DailyTechFlow

**目标**：每天凌晨 3:30 自动运行，生成当日科技新闻的中英文视频 + 图文内容，早晨醒来即可直接发布，顺带为个人小工具项目引流。

---

## 目标用户

- 个人使用（内容创作者本人）
- 受众：微信公众号读者（中文）、X/Twitter 用户（英文）

---

## 核心功能（MVP 范围）

### 内容生成
- 每天自动抓取 **3 条** 科技热点新闻（Tavily Search / Brave Search）
- 基于新闻用 Gemini API 生成：
  - 1 篇中文文章
  - 1 篇英文文章
- 用 GPT-Image-2 为每篇文章生成对应封面图（中英文各一张）

### 视频生成（中英文各一条）
- 时长：**2~3 分钟**
- 新闻数量：**3 条**
- 风格：动态背景 + 文字动画 + 语音旁白
- 工具：Edge-TTS 生成语音，Hyperframes 合成视频

### 内容发布
| 平台 | 内容 | 方式 |
|------|------|------|
| 微信公众号 | 中文图文文章 | **全自动**（微信公众号 API） |
| 微信视频号 | 中文视频 | 手动上传 |
| YouTube | 中英文视频 | 手动上传 |
| X（Twitter）| 英文文章 | 手动发布（文章已自动生成） |

---

## 技术方案

```
Windows 任务计划程序（每天 03:30）
  └─ Python 主脚本
       ├─ [模块1] 新闻抓取       Tavily API / Brave Search
       ├─ [模块2] 内容生成       Gemini API（中英文文章 + 脚本）
       ├─ [模块3] 图片生成       GPT-Image-2（中英文封面各一张）
       ├─ [模块4] 语音生成       Edge-TTS（中文 + 英文旁白）
       ├─ [模块5] 视频合成       Hyperframes（动态背景+文字动画+旁白）
       └─ [模块6] 发布           微信公众号 API（中文文章自动发布）
```

### 可用 Skills
| Skill | 用途 |
|-------|------|
| `tavily-search` | 抓取科技新闻 |
| `brave-search` | 备用新闻源 |
| `edge-tts` | 中英文语音旁白 |
| `gpt-image-2` | 封面图生成 |
| `hyperframes` | 视频合成 |

---

## 非功能性需求

- **费用**：每次运行成本约 $0（全部使用免费 API 额度）
- **运行环境**：Windows 本地，电脑保持开机
- **运行时间**：每天凌晨 03:30
- **输出目录**：`I:\AI\DailyTechFlow\output\YYYY-MM-DD\`（按日期归档）
- **容错**：任意模块失败时记录日志，不中断整体流程，已完成的产物保留

---

## 已知限制与边界

- X/Twitter 自动发布不实现（API 收费 $100/月），英文文章生成后手动发布
- 微信视频号无公开 API，视频手动上传
- YouTube 视频手动上传（暂不实现自动化）
- 依赖本地电脑开机，无云端备份
- Gemini / GPT-Image-2 均依赖免费额度，超限时当天跳过生成

---
